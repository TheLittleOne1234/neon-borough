# Neon Borough

A single-file, top-down cyber-noir crime game for the browser, built with HTML5 Canvas and Web Audio. No install and no external assets.

**Play:** open `index.html` in a modern desktop browser (Chrome, Edge or Firefox).

This is the v14.7 play-test snapshot: police AI, on-foot combat, weapons, and vehicles.

Press F3 in-game for the frame-time overlay.
